\# 🛒 Grocery Management System



A desktop application built with \*\*Java Swing\*\* and \*\*PostgreSQL\*\* to manage a grocery store: products, categories, staff and billing.



\## ✨ Features

\- 🔐 Staff login

\- 📦 Add, edit and display products

\- 🗂️ Manage product categories

\- 👥 Manage staff records

\- 🧾 Generate customer bills



\## 🛠️ Tech Stack

\- Java (Swing, NetBeans GUI Builder)

\- PostgreSQL

\- JDBC



\## 🚀 How to Run

1\. Clone the repo: `git clone https://github.com/98400/grocery-management-system.git`

2\. Open the project in \*\*NetBeans\*\*

3\. Create a PostgreSQL database named `grocery`

4\. Create the tables (schema file coming soon in `database/`)

5\. Add the PostgreSQL JDBC driver (download from jdbc.postgresql.org) to the project libraries

6\. The code connects with `jdbc:postgresql://localhost:5432/grocery`, user `postgres`, password `postgres`. Change these in the code to match your setup

7\. Run `Begin.java`
